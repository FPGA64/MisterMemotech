MTX512 for MiSTer - source

Top level          MTX512.sv (MiSTer wrapper: menu, ROM loader, tape, joystick), MTX512.qpf/.qsf/.sdc, files.qip
rtl/               the core: mtx.vhd (the machine), mtx_tape.sv (WAV and .mtx tape), mtx_save.sv (SAVE to a
                   mounted 64 KB .mtx image), sdx_fdc.sv (the SDX floppy controller, WD1793 on ports 10h-14h, discs as images), mtx_overlay.vhd (the load/verify/save routine, generated by sim/make_overlay.py), mtx_speculator.vhd (the
                   Speculator add-on board: 2K RAM behind ports 1F/7E/7F/FB/FE/FF and the NMI generator, from its schematic), mtx_joy.vhd, mtx_kbd.vhd, sound.vhd,
                   mtx_autorom.vhd (types ROM 3 on the keyboard after a disc change), mtx_xsdram.sv and sdram.sv (the 256KB expansion RAM, kept in the MiSTer's SDRAM), dart.vhd (the
                   serial port of the Communications board, from REMEMOTECH), mtx_col80.vhd (the 80 column board: 6845 registers, the two screen RAMs, the character ROM and a 640 x 480 picture, written from the board's schematic and the MTX-FDX Technical Manual), mtx_romload.sv (where the ROM files from the SD card go),
                   vdp*.vhd, ctc.vhd, memory_map.vhd, clock_divider.vhd, T80*.vhd (Z80), RamRom/ and pll
sys/               MiSTer framework (Template_MiSTer), unmodified
sim/               test rigs: mtx_emu.py is a small Python MTX that runs the real ROMs and the real overlay bytes;
                   tape_model.py decodes WAV tapes the way the OS does; ModelSim testbenches (tb_*.vhd/.sv);
                   col80_model.py is a software model of the 80 column board, make_cpm_test.py and check_cpm_frame.py build and check the
                   whole-core CP/M boot bench (they need the CP/M bootstrap PROM, the character ROM and a CP/M disc, which are not included)

Build: Quartus Prime Lite 17.0.2, from this folder:   quartus_sh --flow compile MTX512
Output: output_files/MTX512.rbf

The Memotech OS, BASIC and ASSEM ROMs are not included. At run time they are read from
games/MTX512/boot.rom, boot1.rom, boot2.rom on the SD card. The sim scripts expect those three files in a
folder you point them at (see ROMDIR in sim/mtx_emu.py), and some also expect a TOSEC MTX collection.

The Speculator is switched off in this build, and removed from the menu
------------------------------------------------------------------------
The source contains the Speculator add-on board (rtl/mtx_speculator.vhd, written from the board's published
schematic) and a player for ZX Spectrum .tap tapes (in rtl/mtx_tape.sv). In this build they are switched off and
taken out of the menu: there is no "Speculator board" entry, "Insert Tape" does not offer .tap files, and the board
is tied off (SPEC_EN is 0, not a menu setting, so a setting saved by another build cannot turn it on).

Why: the Speculator is the Memotech add-on (designed by Tony Brewer, 1985) that runs ZX Spectrum games on an MTX512.
To be of any use it needs Memotech's Speculator program and the Spectrum games themselves. Those are other people's
work and are not distributed with this core, so the public build leaves the option out. spec_option.vh holds the
switch, with the same explanation, and says how to build with it: change its three definitions and compile as
usual. You then need your own copy of the program and of the games.
